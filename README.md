# 손이가 웨딩 - 웨딩 비교견적 플랫폼

웨딩 비교견적 플랫폼의 홈페이지입니다.

## 기술 스택

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS

## 시작하기

### 의존성 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

## 주요 기능

- 반응형 디자인 (모바일, 태블릿, 데스크톱)
- 헤더 네비게이션 (햄버거 메뉴 포함)
- 히어로 섹션
- 상품 카드 그리드 레이아웃
- 라우팅 구조
